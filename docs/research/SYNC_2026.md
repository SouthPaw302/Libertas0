# SYNC Research — October 2026

## Realtime shared state
SharedArrayBuffer plus Atomics provides synchronized shared memory across execution agents. Atomic loads/stores are tear-free and sequentially consistent for their integer sequence guard. Libertas0 uses an atomic sequence lock around a compact Float64 leader snapshot so the follower discards any concurrent partial read.

## Audio-rate control
Web Audio AudioParam automation is defined against AudioContext.currentTime and is updated by the render engine. The existing deck playback-rate parameter is already an a-rate worklet parameter. Phase 6 keeps manual rate on that path and layers the follower's bounded sync correction inside the same realtime processor.

References:
- https://developer.mozilla.org/en-US/docs/Web/API/AudioParam
- https://webaudio.github.io/web-audio-api/

## Controller choice
The reference controller is deliberately small and deterministic:
1. exact tempo ratio for steady-state frequency lock;
2. wrapped nearest-beat phase error;
3. proportional phase correction converted into rate units using follower BPM;
4. hard correction bound;
5. deadband;
6. one-pole rate smoothing.

This is phase-lock behavior, but it does not introduce another oscillator or timer. All state is derived from the two proven source-frame timelines.

## Why no periodic corrective seek
A seek changes transport position discontinuously and is directly audible on program material. The Phase 6 controller must prove convergence using rate correction alone after engagement. Hard alignment may later exist as an explicit user action or scheduled launch operation, not as hidden sync maintenance.
