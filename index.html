Quick test

You do not need to use every panel. For a basic listening test:

  1. Choose an audio file on Deck A and Deck B, then press Load.
  2. Press Play A and Play B.
  3. Use SYNC B to A, then try the crossfader, EQ/filter, cue, loop, or jog controls.
  4. Use the status boxes only when you want the technical measurements.
